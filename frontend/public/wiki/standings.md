# Standings Page

The Standings page is the home page and shows the current league rankings.

## What You Can See

| Column | Description |
|--------|-------------|
| **Rank** | Wrestler's position based on win percentage |
| **Wrestler** | The wrestler's name |
| **Division** | The brand/division the wrestler is assigned to |
| **W / L / D** | Total wins, losses, and draws |
| **Win %** | Win percentage calculated from their record |

## How Rankings Work

Wrestlers are ranked by their win percentage. Wrestlers with more wins and fewer losses will appear higher on the standings. You can filter standings by division or view all-time vs. per-season records.

**Formula:** Win % = Wins / (Wins + Losses + Draws) x 100
